# 运动类应用

本目录收录了各类运动类应用，为用户提供丰富的应用资源。

## 即刻运动TV版
即刻运动TV版是一个非常好用的健身软件，海量健身的课程，系统性的跟练视频，不管你是有健身基础的照样齐全的小白，总能够找到适宜你的课程。如果你想要有更好或者更加衰弱的身材，那末就能够来下载这个电视版的健身app，相持跟练就能够了。

## Keep健身TV版
Keep健身TV版在家都能用的健身工具，轻松拥有好身材。真人录制健身视频，全程语音指导练习，多种训练课程任你选，想练哪里练哪里。训练完成后扫描二维码，一键上传训练记录到Keep，与更多好友分享健身成果。Keep——只为改变(Time For Change)！

## 每日瑜伽
每日瑜伽TV版是一款专为智能电视用户打造的家庭瑜伽训练软件，致力于帮助用户在家中舒适、科学地进行瑜伽练习。平台提供丰富的动态瑜伽课程，覆盖初学入门、塑形减脂、核心训练、舒缓放松等多个方向，课程由专业导师编排，语音引导清晰，配合柔和音乐营造沉浸式练习氛围。与手机App相比，TV版本以更大屏幕呈现动作细节，利于模仿学习，尤其适合追求画面清晰度和练习姿势标准化的用户。它不仅打破了“必须去瑜伽馆”的时间与空间限制，还通过打卡记录、个性推荐、社群互动等功能，激发用户持之以恒的动力。

## 糖豆广场舞TV版
糖豆广场舞TV版是一款专业的广场舞教学类电视应用，这里汇聚了全国上千名专业广场舞老师、广场舞达人进行在线教学，亲身示范教学，超过200万的广场舞视频教程供你下载学习。在APP里，有最专业的广场舞演示视频，大家可以通过详细的视频与图文资料，让你掌握广场舞的每一个细节动作，学会更多的广场舞跳法，让你的生活更加丰富多彩。
