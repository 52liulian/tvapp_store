##应用介绍
YourTV又叫你的电视TV主打IPTV和网页视频播放，支持遥控器与触摸两种方式。能提供央视、卫视、少儿和地方频道内容，频道覆盖广泛且全天24小时持续播出，可直接通过搜索功能定位。同时支持回放功能，即便错过内容也能后续观看，整体播放保持高清流畅，通过整合互联网公开直播源，构建起覆盖全国主流频道的直播平台。
