##应用介绍
电视家是一款非常好用的电视盒子类应用，包含了很多的影视资源让用户可以挑选查看，并且还能够收藏喜欢的频道，以便可以随时打开收看，还可以随时开启回放，在后台全部都可以实时的保存播放记录，方便用户可以更好的管理，有需要的用户快来下载看看吧。
