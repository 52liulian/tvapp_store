##应用介绍
OurTV是一款专为电视直播爱好者设计的软件，提供了丰富的电视频道资源，包括央视、卫视及港澳等多个地区的频道。软件支持高清、超清和蓝光等多种画质选择，确保用户能够享受到清晰、流畅的观看体验。
