##应用介绍
应用管家是专为安卓系统打造的应用和文件管理软件，它可以获取到电视中的所有应用程序和文件数据，方便用户进行删除、移动等；如果连接手机后，还可以将手机中的应用传输到电视上进行安装，这样就不需要U盘了。
